# Supporting Skill registry

Read the linked SKILL.md when its trigger applies. These seven Skills are bundled; no separate KV plugin installation is required for their procedures. The runtime still needs ordinary tools for external research or file rendering.

| Skill | Sole procedural ownership | Trigger |
|---|---|---|
| [kv-passage-faithfulness-check](../../kv-passage-faithfulness-check/SKILL.md) | Evaluate textual warrant, overreach, and applications | Contested claims, forced themes, final theological review |
| [kv-source-transparency-check](../../kv-source-transparency-check/SKILL.md) | Classify and disclose the source base | Blended notes/research, source-sensitive claims, publication/handoff source statement |
| [kv-scripture-formatting-check](../../kv-scripture-formatting-check/SKILL.md) | Quotations vs summaries, labels, references, attribution, BLB handling | Scripture cleanup and distribution |
| [kv-multi-asset-throttle](../../kv-multi-asset-throttle/SKILL.md) | Choose controlling output and sequence across domains | Multiple additional downstream asset families |
| [kv-one-page-handout-generator](../../kv-one-page-handout-generator/SKILL.md) | Condense completed content into a requested learner handout | Explicit handout request after teaching exists |
| [kv-print-ready-packet-polish](../../kv-print-ready-packet-polish/SKILL.md) | Polish an existing packet without adding teaching | Explicit cleanup/print-polish request |
| [kv-interaction-evaluator](../../kv-interaction-evaluator/SKILL.md) | Recommend whether/type of interaction | Explicit interaction decision; no learner-facing build |

The core owns devotional writing and editorial review. Do not duplicate those specialist procedures here. For this plugin, simple social copy remains a devotional derivative; campaigns, scheduling, and platform packages belong downstream. Default source checks are proportionate, not seven full reports on every short answer.

## Attribution and permission context

For Scripture checks, read the user's active permission file when one applies. An organization's grant must not be treated as permission for another organization or every plugin user. The private ministry permission document is not bundled into this reusable plugin. Supply it through the relevant Project when needed. Keep The Crucible's Fire, Beacon Learning Company, and Lone Star Speech and Debate Academy contexts separate.

An acknowledgment is not a license grant or a substitute for checking applicability. Never assert the user owns a special grant merely because this plugin is installed. Formatting and permission-awareness procedure remains with the Scripture Skill.
